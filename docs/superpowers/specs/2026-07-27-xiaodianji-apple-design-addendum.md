# 小店记 MVP Apple 风格设计补充

本补充与 `2026-07-27-xiaodianji-mvp-design.md` 一起构成前端实现基准。前端采用 `apple-design` 的设计原则，但不复刻 iOS 外观。视觉目标是让传统小店店主感到平静、熟悉、可信和可控。

## 视觉与布局

- 首页使用纯白背景和单一纯色蓝主操作，不使用渐变、光晕、拟物账本纹理或装饰性插画。
- 信息采用开放式分组和少量必要边框，避免多层卡片、胶囊标签和玻璃材质叠加。
- 默认使用系统中文字体；正文、金额和操作文字均采用适老字号，触控区域不小于 44px。
- 底部操作栏尊重安全区。确认页保持“摘要 → 商品明细 → 合计 → 原始凭证 → 确认/取消”的稳定空间顺序。

## 状态与交互

- 低置信度使用琥珀色边框、浅色背景和明确文字说明共同提示，不只依赖颜色，也不使用错误态红色制造误解。
- 按下时立即提供缩放或颜色反馈；普通界面动效采用无过冲的短促缓动。
- 所有动效支持 `prefers-reduced-motion`；半透明材质支持降低透明度时的实色降级。
- 所有关键操作使用直接、具体的中文文字，不以图标替代“确认记账”“取消”“查看提醒”等动作。
